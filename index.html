🚜 FS20 Mod Studio

Protótipo inicial • Android + Chrome • análise local de mods

1. Carregar mod do FS22

Escolha um ZIP do mod ou selecione os arquivos I3D, SHAPES, XML e texturas. Os arquivos são lidos no navegador; esta versão não envia seu mod para um servidor.

Solte aqui um ZIP ou arquivos do mod (se o Chrome permitir).
Pronto. Carregue um ZIP ou os arquivos do mod.

2. Visualizador 3D

A prévia 3D aparecerá aqui. Este protótipo aceita OBJ/GLB/GLTF para visualização direta; I3D/SHAPES ainda precisam do leitor específico.

Arraste para girar • use dois dedos/roda para zoom quando disponível. Um modelo de demonstração aparece se nenhum modelo 3D compatível for carregado.

4. Diagnóstico I3D

5. Análise do XML

Selecione um XML para analisar tags, atributos e referências.

6. Conversão assistida para FS20

A conversão automática completa ainda não está implementada. Por enquanto, a ferramenta faz inventário e diagnóstico, sem alterar seus originais. Isso evita gerar um mod aparentemente convertido mas quebrado.
